  - Core CSS reset / base styles.

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run using one of the following:
   - Open `index.html` directly in a browser, **or**
   - Use a local server (recommended), e.g. VS Code **Live Server**.
